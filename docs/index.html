Batocera scrapes box art, descriptions and videos into a gamelist.xml buried in every system's ROMs folder. batocera-scrap-manager pulls all of that into one centralized registry you can browse, fix and sync back — from a terminal, or from a phone on your couch.

THE PROBLEM

One folder per system. Zero overview.

Every system you scrape gets its own gamelist.xml, its own copy of the box art, its own video clips. There is no single place to see what's been scraped, what's missing, or what got mangled by a bad scrape — and no way to fix an entry short of hand-editing XML and hoping the next scrape doesn't clobber it again.

batocera-scrap-manager reads what Batocera already scraped, centralizes it into one registry, and gives it back to you as something you can actually browse, correct and protect.

megadrive/gamelist.xml
<game id="1">
  <path>./Sonic.zip</path>
  <name>Sonic the Hedgehog</name>
  <desc>???</desc>
  <rating>0.0</rating>
</game>
… × one file per system, never seen at once
HOW IT WORKS

One registry, two directions

Import pulls scraped data from your ROMs folders into the registry, deduplicating and skipping anything never actually scraped. Complete (fill gaps only) or Replace (registry wins) send it back out, your call which rule applies.

FEATURES

Why bother

Eight reasons this beats grepping through XML by hand.

01

Centralized registry

Every system's metadata and media, indexed once, however many ROMs folders you watch.

02

Browse from anywhere

A built-in web server puts the whole registry on your LAN — one page per system, one page per game.

03

Fix it in the browser

A pre-filled form corrects name, description, rating, genre and more. No XML editor required.

04

Protect what you fixed

Hand-edited fields — and fully protected games — survive the next update untouched.

05

Media, handled

Upload, replace or remove cover art, video, marquee and thumbnail — safely named, size-checked.

06

Two-way sync

Import fills the registry from your ROMs folders; Complete or Replace sends it back, your call.

07

Crash-safe writes

gamelist.xml is swapped in atomically — a power cut never leaves it truncated.

08

Docker-ready

Ships as a non-root container, with docker-compose and PUID/PGID for NAS setups out of the box.

SAFETY

Nothing happens without asking

  • Confirm before writing. Anything that touches your ROMs folders or deletes data names exactly what it's about to do first.
  • Corrections stick. A value you fixed by hand is never silently overwritten by a later scrape.
  • One job at a time. Import and Complete share a single background slot — no race between the two.
  • Failures are reported, not hidden. A site that fails to regenerate is flagged as out of date, never disguised as success.
MOBILE

Built for the couch, not just the desk

On a small screen, a game becomes a compact row — thumbnail and name — instead of a full-width card, so a dozen fit on screen instead of one. Every link and button stays big enough to tap.

INSTALL

Pick your poison

Requires Go 1.26+, or nothing at all if you'd rather run the Docker image.

go install github.com/neolao/batocera-scrap-manager@latest
git clone https://github.com/neolao/batocera-scrap-manager.git
cd batocera-scrap-manager
go build -o batocera-scrap-manager .
docker build -t batocera-scrap-manager .
# then configure and run — see the README for the full walkthrough
cp .env.example .env
# edit .env: registry / roms / config paths, PUID / PGID
docker compose up -d
